While structuring the blog post card in Task 2, I almost used a generic <div> with a custom class to hold the post date and main content. Instead, I replaced the container with the semantic <article> tag to give the blog entry meaningful structure for screen readers. I also used the <time> tag with a datetime attribute instead of a <div> for the publication date to improve machine readability. Furthermore, I swapped out clickable <span> elements inside wrapper <div>s for actual <nav> and <a> anchor tags. Using these native semantic elements eliminated unnecessary div soup and ensured the page fully complies with accessibility standards.
